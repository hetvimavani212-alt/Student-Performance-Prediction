# Student Performance Prediction System

## About the Project
The Student Performance Prediction System is a Machine Learning project that predicts student academic performance based on input features.

The project uses a Random Forest Regressor to estimate student performance and provides an interactive interface using Streamlit.

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Machine Learning Model
- Algorithm: Random Forest Regressor
- Hyperparameter Tuning
- Model Evaluation
- Cross-Validation

## Model Evaluation
- MAE: 4.8
- RMSE: 6.15
- Testing R² Score: 0.7602
- Training R² Score: 0.9481
- Cross-validation MAE: 4.92

## Features
- Student performance prediction
- Interactive Streamlit interface
- Machine Learning-based predictions
- Model evaluation

## How to Run

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`
